# Анодик

Утилита командной строки для более удобного управления riscv cmake sdk.

# Возможности

1. Управление пакетами и установкой инструментов для SDK: (компилятор, система сборки, языковой сервер, openocd, дебаггер);
2. Конфигурация и сборка проектов;
3. Простая кодогенерация;
4. Управление openocd и gdb.

# Сборка

Для сборки потребуется компилятор go.
Собрать под текущую систему можно с помощью

```sh
go build
```

Собрать под все поддерживаемые системы со статической линковкой можно с помощью

```sh
./build-all.sh
```

# Использование

```sh
anodik help
```
